# Neowow 操作与费用

## 环境与接入

Skill 是给 Agent 的任务方法，不附带 Neowow 账号、浏览器权限、客户资产或积分。使用者需要支持 Skill 的 Agent、已登录的 Neowow、账号绑定资产、图库入口与可保存结果的位置。

优先复用环境中已授权且有文档的 Neowow 接口；没有时，通过当前环境支持的浏览器控制工具操作已登录页面。先读工具文档，观察当前 UI 后再操作，不照抄其他电脑的本地路径、浏览器 ID、节点 ID 或私有接口。不把页面内部网络接口猜测为公开 API。不使用隐藏接口获取登录凭据。

没有可用浏览器控制能力时明确说明缺少的能力，指导接入后再执行在线环节；不能把离线写出的提示词当成已经生图。登录由用户在浏览器完成，不请求对话粘贴凭据。只使用指定画布，操作期间避免多人同时修改同一节点。

## 提交前回读

1. 观察当前模型选项、参考图绑定方式、画幅、分辨率、张数、单次费用及余额。历史试用过 Neo Nano 2.1，不代表当前仍可用或最优；以页面和本次要求为准。
2. 每个节点列出“参考图编号 → 实际图片 → 用途”，缩略图和编号逐项对应；移除重复、失效或冲突引用。
3. 选择符合交付要求的参数；人物换装不强制三视图格式，场景图按本次画幅。切走再返回，回读完整提示词、引用及参数，确认真正保存。
4. 说明本轮操作、张数、预计积分、授权范围与重试上限。包括换装、重生成和收费预览；页面不显示费用时先核实，不猜价格。每轮结算证据单独记录，授权预算不等于实际消耗。
5. 只提交一次，等待实际结果。如果超时，先查看任务状态／历史，不盲目重复点击，避免重复扣费。截图或记录可见的扣费回执，排除其他任务影响后才归因。

## 提示词骨架

以下是语义骨架，先按工具实际参考图顺序改写编号，与已有模板合并并删除冲突约束，不机械叠加。

### 人物换装

> 以参考图中的账号人物为同一身份，只调整为本次确认的服装、鞋子和配饰。服装参考只提供穿搭，不替换人物脸型、五官、体型与发型。保留人物自然质感，不输出多宫格，不增加未指定饰品。输出可供后续场景人物替换使用的清楚人物参考。

### 场景图人物替换

> 直接编辑场景原图，只将目标人物替换为确认的换装人物参考中的同一个人。场景原图提供构图、裁切、原姿势、现场光线、环境与车辆；人物参考提供身份及已确认穿搭。保留车辆结构、轮毂、标识和内饰，保留手机、安全带等指定现场交互物。人物受光、遮挡、接触阴影及清晰度与现场一致。只输出一张照片，不输出资料板、拼图或多宫格。车内自拍保留原裁切，不为展示全身服装扩大画面。

提示词不能保证车辆细节准确，生成后必须对照检查并修复。脸型有漂移时回到账号原始身份基准，不继续拿漂移图作为唯一新基准。

## 保存与恢复

节点名包含账号／任务、场景、版本、状态。生成、修复和送审版本保留对应关系。上传本地修复图后等待图片实际加载，再重新打开画布确认服务器保存。不能只凭本地预览、上传回执或“请求已接受”宣称已保存。

遇到配置丢失、重复引用等操作错误先修正配置。同类错误无改善或预算触顶时停止追加；不要用“再试一次”无限消耗。界面变化时重新观察，不使用过期坐标反复点击。
